# Mi página web sencilla

## Descripción

Proyecto básico de una página web estática en español. La página principal muestra un saludo y algunos textos de ejemplo. El repositorio también incluye una hoja de estilos CSS y una página de contacto.

## Requisitos

- Un navegador web moderno.
- Git, si se desea clonar el repositorio.

No se necesitan dependencias ni herramientas de compilación.

## Instalación

Clona el repositorio:

```bash
git clone <URL-del-repositorio>
```

Después, abre la carpeta del proyecto. Si ya tienes los archivos, no es necesario instalar nada.

## Ejecución

Abre `index.html` directamente en un navegador web. También puedes servir la carpeta con cualquier servidor estático local.
